How an election moves through Rollcall

Three steps, in order — because that's the actual sequence every election follows here.

01 — Set up

Create the election

Name it, add candidates, set an opening and closing time, and upload the electoral roll as an Excel or CSV file.

02 — Vote

Voters check in and cast a ballot

A voter enters their voter ID or email. Rollcall matches it against the roll — only listed voters can proceed, and only once.

03 — Declare

Winner goes out automatically

The moment the window closes, results lock in and a notification is sent to the winner's email address from the roll.
